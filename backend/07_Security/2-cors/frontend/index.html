CORS – Cross-Origin Resource Sharing

Abrí la consola del navegador (F12) para ver los errores de CORS.

Ruta permitida: el servidor incluye el header Access-Control-Allow-Origin con tu origen.
Ruta bloqueada: el servidor NO incluye ese header → el navegador bloquea la respuesta (error en consola).
