⚙️ Flujo del Protocolo

Cómo funciona Digest Auth

1Cliente pide el recurso protegido (sin credenciales)
2Servidor responde 401 con nonce, realm y qop en WWW-Authenticate
3Cliente calcula: HA1=MD5(user:realm:pass), HA2=MD5(method:uri)
4Cliente calcula: response=MD5(HA1:nonce:nc:cnonce:qop:HA2)
5Cliente envía la request con el header Authorization:Digest
6Servidor recalcula el hash y lo compara con el del cliente
