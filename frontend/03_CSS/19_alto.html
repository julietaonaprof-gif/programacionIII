Propiedad height en CSS — todos los valores

Funciona como width pero para el alto. Hay algunos trucos importantes.

⚠️ Advertencia: height fijo puede causar problemas si el contenido crece más que el valor. En muchos casos es mejor usar min-height, que garantiza un mínimo pero deja que el elemento crezca si hace falta.

1. Píxeles (fijo)

height: 100px; — siempre 100px:

100px fijo

2. Porcentaje (del padre — con truco)

height: 50%; — pero el padre tiene que tener altura:

50% del padre (150px)

Si el contenedor padre NO tiene altura definida, el 50% no funciona y se comporta como auto. Es una de las diferencias más confusas respecto a width.

3. vh (de la ventana)

height: 30vh; — 30% del alto de la ventana. Redimensioná verticalmente:

30vh

4. max-height (límite máximo)

max-height: 150px; + overflow: auto; = scroll si pasa:

Línea 1 — Lorem ipsum dolor sit amet

Línea 2 — consectetur adipiscing elit

Línea 3 — sed do eiusmod tempor incididunt

Línea 4 — ut labore et dolore magna aliqua

Línea 5 — Ut enim ad minim veniam

Línea 6 — quis nostrud exercitation

5. min-height (la MÁS recomendada)

min-height: 200px; — mínimo 200px, pero puede crecer:

min-height: 200px

Esta es la que más vas a usar. En cards, secciones, hero sections: preferí min-height a height.

6. auto (default)

Sin height definido, la caja mide lo que ocupa su contenido:

height: auto (contenido)

7. fit-content

Casi igual a auto para height:

fit-content

8. min-content

Lo más bajo posible manteniendo el contenido legible:

min-content

9. max-content

Se adapta al contenido completo (similar a auto):

max-content

10. rem (relativo a tipografía)

height: 10rem; = 160px:

10rem

11. calc()

height: calc(50vh - 50px); — media pantalla menos 50px:

calc(50vh - 50px)

Muy útil para "contenido que ocupa toda la pantalla menos la altura del header".

12. clamp() (responsive con límites)

height: clamp(100px, 20vh, 250px); — entre 100 y 250px:

clamp responsive

Truco clásico: hero section de pantalla completa

height: 100vh; + flex centrado — ocupa toda la pantalla visible:

HERO 100vh

Resumen de todos los valores

Valores absolutos

  • 100px — píxeles.
  • 10rem, 5em — relativos a tipografía.

Relativos al padre

  • 50% — porcentaje (requiere padre con altura).

Relativos a la ventana

  • 50vh — % del alto del viewport.
  • 100vh — pantalla completa.

Palabras clave

  • auto — se adapta al contenido (default).
  • fit-content, min-content, max-content.

Límites

  • max-height — tope superior.
  • min-height — el que más vas a usar.

Funciones modernas

  • calc() — cálculos.
  • clamp(min, ideal, max) — responsive con límites.
  • min(), max() — el menor/mayor de varios.

Diferencias importantes entre height y width

1. Comportamiento por defecto

  • width: auto en un <div> → ocupa todo el ancho.
  • height: auto en un <div> → mide lo que ocupa el contenido (bien poquito).

2. Porcentajes

  • width: % → funciona siempre (el ancho del padre suele estar definido).
  • height: % → solo funciona si el padre tiene altura definida. Si no, se ignora.

3. Prioridad en el uso

  • Para width, se usa mucho width directo + max-width.
  • Para height, se prefiere min-height a height directo.

Reglas prácticas

  • Si dudás entre height o min-height, usá min-height. Así tu contenido nunca se corta.
  • Para hero sections: min-height: 100vh;.
  • Para contenido con scroll interno: max-height: 400px; overflow: auto;.
  • Para pantalla completa menos el header: min-height: calc(100vh - 60px);.
  • Para que % funcione: asegurate de que el padre tenga altura definida.
