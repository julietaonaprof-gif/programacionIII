Box Model — Modelo de caja

Todo elemento HTML es una caja rectangular con 4 áreas: content, padding, border y margin. Entender esto es la base de todo el layout en CSS.

1. Las 4 áreas visualizadas

Esta caja tiene las 4 áreas bien marcadas:

CONTENT
(width: 200px
height: 80px)

El fondo naranja punteado es el padre. La caja azul es el elemento. Entre la caja y el padre ves el margin (30px). El borde naranja es el border (8px). El espacio azul alrededor del texto es el padding (20px). El texto en sí es el content.

2. Padding (relleno interno)

Espacio entre el contenido y el borde. Se pinta con el background:

padding: 10px (igual en los 4 lados)
padding: 30px 10px (vertical / horizontal)
padding: 5px 20px 40px 60px (top / right / bottom / left)

3. Border (borde)

Sintaxis: border: grosor estilo color;

border: 2px solid (línea)
border: 3px dashed (rayas)
border: 4px dotted (puntos)
border: 5px double (doble línea)
border-left solo (6px)

4. Margin (margen externo)

Espacio entre la caja y sus vecinos. No se pinta:

margin: 10px
margin: 40px (más separación)
margin: 20px auto (centrado horizontal)

Truco clásico: margin: 0 auto; centra un elemento horizontalmente dentro de su padre (siempre que tenga un ancho definido).

5. ⭐ box-sizing: la propiedad más importante

Esto es LO MÁS IMPORTANTE del box model. Determina si width/height incluyen padding y border, o no.

Las dos cajas de abajo tienen exactamente el mismo CSS (width: 200px, padding: 20px, border: 5px). La única diferencia es box-sizing:

CONTENT-BOX
Tamaño real: 250px
BORDER-BOX
Tamaño real: 200px

La diferencia en números

  • content-box (default): el ancho real es width + padding izq/der + border izq/der = 200 + 40 + 10 = 250px.
  • border-box: el ancho real es exactamente width = 200px. El content se achica a 150px para compensar padding y border.
Recomendación universal: poné esto al principio de tu CSS y olvidate de los bugs de tamaño: 
* {
  box-sizing: border-box;
}

6. overflow — cuando el contenido se sale

Todas estas cajas son de 200×80px con mucho texto adentro. Mirá cómo cambia el comportamiento:

visible (default): se sale

Texto muy largo que no entra en la caja y se desborda visiblemente por fuera sin respetar los límites marcados.

hidden: se corta

Texto muy largo que no entra en la caja pero queda cortado al llegar al borde sin mostrarse.

scroll: barras siempre

Texto muy largo con scroll. Aparecen barras aunque no hagan falta en el otro eje.

auto: scroll solo si hace falta (recomendado)

Texto muy largo con overflow auto. La barra aparece solo cuando es necesaria, por lo que la caja se mantiene más limpia.

Resumen

  • Content — el contenido (texto, imagen...). Controlado por width y height.
  • Padding — relleno interno. Se pinta con el background.
  • Border — el borde. grosor estilo color.
  • Margin — espacio externo, transparente.
  • box-sizing: border-box — incluye padding y border en el width. RECOMENDADO.
  • overflow — qué hacer con el contenido que se sale (auto es el más útil).

Reglas prácticas

  • Poné * { box-sizing: border-box; } al inicio de tu CSS. Siempre.
  • Para centrar un elemento con ancho fijo: margin: 0 auto;
  • Si un elemento tiene contenido variable, usá overflow: auto;
  • Para eliminar el margin/padding default del navegador: * { margin: 0; padding: 0; } (reset básico).
