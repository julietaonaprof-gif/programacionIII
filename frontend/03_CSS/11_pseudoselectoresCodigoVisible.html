Pseudo-selectores con código visible

Cada ejemplo muestra el HTML, el CSS aplicado, y el resultado en vivo.

✅ Grupo 1: funcionan en cualquier tag

1.1 — :hover

HTML
<div class="hover-demo">Soy un DIV</div>
<span class="hover-demo">Soy un SPAN</span>
<h4 class="hover-demo">Soy un H4</h4>
CSS
.hover-demo:hover {
  background: #1a4d7a;
  color: white;
  cursor: pointer;
}
RESULTADO (pasá el mouse por encima)
Soy un DIV
Soy un SPAN

Soy un H4

1.2 — :first-child y :last-child

HTML
<div class="lista-demo">
  <p>Soy el primer párrafo.</p>
  <p>Soy un párrafo del medio.</p>
  <p>Soy el último párrafo.</p>
</div>
CSS
.lista-demo > *:first-child {
  color: #c0392b;
  font-weight: bold;
}
.lista-demo > *:last-child {
  color: #27ae60;
  font-weight: bold;
}
RESULTADO

Soy el primer párrafo.

Soy un párrafo del medio.

Soy el último párrafo.

1.3 — :nth-child(even) — zebra striping

HTML
<table class="tabla-demo">
  <tr><th>Nombre</th><th>Edad</th></tr>
  <tr><td>Ana</td><td>25</td></tr>
  <tr><td>Juan</td><td>32</td></tr>
  <tr><td>Lucía</td><td>28</td></tr>
  <tr><td>Carlos</td><td>45</td></tr>
</table>
CSS
.tabla-demo tr:nth-child(even) {
  background: #f4f1ec;
}
RESULTADO
Nombre Edad
Ana 25
Juan 32
Lucía 28
Carlos 45

1.4 — ::before y ::after

HTML
<p class="con-icono">Soy un párrafo con estrella antes</p>
<div class="con-icono">Soy un div con estrella antes</div>
<h4 class="con-sufijo">Soy un h4 con flecha después</h4>
CSS
.con-icono::before {
  content: "⭐ ";
  color: #e8941e;
}
.con-sufijo::after {
  content: " ←";
  color: #c0392b;
  font-weight: bold;
}
RESULTADO

Soy un párrafo con estrella antes

Soy un div con estrella antes

Soy un h4 con flecha después

⚠️ Grupo 3: solo en enlaces

3.1 — :link, :visited, :hover, :active

HTML
<a href="https://wikipedia.org">Enlace a Wikipedia</a>
<a href="#">Enlace de ejemplo</a>
CSS
a:link    { color: #1a4d7a; }         /* sin visitar */
a:visited { color: #8e44ad; }         /* ya visitado */
a:hover   { text-decoration: none; }  /* mouse encima */
a:active  { color: #c0392b; }         /* clickeado */
RESULTADO

Enlace a Wikipedia (violeta si ya lo visitaste)

Pasá el mouse por encima (se quita el subrayado)

Orden recomendado: LVHA (Link, Visited, Hover, Active). Si los ponés en otro orden, el :hover puede no funcionar.

⚠️ Grupo 5: solo en bloques

5.1 — ::first-letter

HTML
<p class="parrafo-capital">
  Lorem ipsum dolor sit amet...
</p>
CSS
.parrafo-capital::first-letter {
  font-size: 3rem;
  font-weight: bold;
  color: #c0392b;
  float: left;
  line-height: 1;
  padding-right: 0.1em;
}
RESULTADO

Lorem ipsum dolor sit amet, consectetur adipiscing elit. La primera letra se agranda y sale como una "capital" estilo libro.

5.2 — ::first-line

HTML
<p class="parrafo-primera-linea">
  Esta es la primera línea...
</p>
CSS
.parrafo-primera-linea::first-line {
  font-weight: bold;
  color: #1a4d7a;
}
RESULTADO

Esta es la primera línea del párrafo, que aparece en negrita y azul. Todo el resto del texto queda en formato normal, aunque el texto sigue y sigue sin aplicar estilo especial a estas líneas.

❌ Dónde NO funcionan los pseudo-elementos

Intento fallido: ::before en una <img>

HTML
<img class="intento-pseudo" src="foto.jpg">
CSS
img.intento-pseudo::before {
  content: "Esto no se va a ver";
  color: red;
}
RESULTADO

El ::before no se ve. Las imágenes son void elements.

Solución correcta: envolver en un contenedor

HTML
<figure class="con-icono">
  <img src="foto.jpg">
</figure>

Ahora ::before se aplica al <figure> (que sí lo acepta) y envuelve la imagen correctamente.

Tabla resumen

Pseudo-selector ¿Dónde funciona?
:hover, :focus, :active Cualquier tag visible
:first-child, :last-child, :nth-child() Cualquier tag que sea hijo
:not(), :is(), :has() Cualquier tag
::before, ::after Casi todos (NO en void: img, input, br)
:checked Solo checkbox, radio, option
:disabled, :enabled Solo elementos de formulario
:required, :valid, :invalid Solo inputs de formulario
:link, :visited Solo <a> con href
::placeholder Solo <input> y <textarea>
::first-letter, ::first-line Solo elementos de bloque
::marker Solo <li> con list-style
::selection Cualquier tag con texto seleccionable
