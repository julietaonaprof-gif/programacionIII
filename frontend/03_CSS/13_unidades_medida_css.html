Unidades de medida en CSS

CSS tiene dos familias: absolutas (fijas) y relativas (dependen del contexto).

Absolutas

Su tamaño es fijo, no cambia según el contexto.

Píxeles (px)

La más usada de las absolutas. Se basa en el píxel físico de la pantalla:

200px fijo

Puntos (pt)

1pt = 1/72 de pulgada. Ideal para impresión, no tanto para pantallas:

150pt

Pulgadas (in), centímetros (cm) y milímetros (mm)

Útiles solo para impresión. En pantalla no son precisos:

2in (pulgadas)
5cm
30mm

Regla práctica: en web usá casi siempre px. El resto (pt, in, cm, mm) es para hojas de estilo destinadas a impresión.

Relativas

Dependen de otra medida (el padre, el html, la ventana...).

em — relativa al padre

1em = el font-size del elemento padre. Si el padre mide 20px, 1.5em = 30px:

Padre con font-size: 20px
Hijo con font-size: 1.5em → 30px

rem — relativa al <html>

1rem = el font-size del <html> (por defecto 16px). No depende del padre:

Padre con font-size: 20px
Hijo con 1.5rem → 24px (ignora al padre)

rem es la más recomendada hoy en día para tipografía, porque es predecible y respeta las preferencias de accesibilidad del usuario (si aumenta el tamaño de fuente en el navegador, todo escala).

Porcentaje (%)

Relativo al contenedor padre. El padre mide 500px:

Padre de 500px
50% del padre (250px)
25% del padre (125px)

vw / vh — relativas a la ventana

1vw = 1% del ancho del navegador. 1vh = 1% del alto. Redimensioná la ventana:

50vw (la mitad de la ventana)
20vh (20% del alto de la ventana)

ch — ancho de carácter

1ch = el ancho del carácter "0" en la fuente actual. Útil para columnas de texto de ancho "natural":

40ch (unos 40 caracteres)

Tabla resumen

Absolutas (fijas)

  • px — píxeles. La más usada en web.
  • pt — puntos (impresión).
  • in, cm, mm, pc — físicas (impresión).

Relativas

  • em — relativa al padre.
  • rem — relativa al <html>. Recomendada para tipografía.
  • % — porcentaje del contenedor.
  • vw / vh — % del viewport (ventana).
  • ch — ancho del carácter "0".
  • ex — altura de la "x" (poco usada).

Cuándo usar cada una

  • px → bordes finos, sombras, elementos que no deben escalar.
  • rem → tamaño de fuente (recomendado sobre px por accesibilidad).
  • em → padding/margin que deben escalar con la fuente del elemento.
  • % → anchos de layouts responsive.
  • vw / vh → hero sections, elementos que ocupan la pantalla.
  • pt, cm, mm → solo en hojas de estilo para impresión.
