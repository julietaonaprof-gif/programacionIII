Propiedad width en CSS — todos los valores

Desde las formas más simples hasta las modernas.

1. Píxeles (fijo)

width: 200px; — siempre 200px, sin importar nada:

200px fijo

2. Porcentaje (del padre)

width: 50%; — la mitad del contenedor padre:

50% del padre
100% del padre

3. vw (de la ventana)

width: 50vw; — la mitad de la VENTANA (ignora al padre):

50vw

4. max-width (límite máximo)

width: 100%; max-width: 300px; — crece pero no más de 300px:

max 300px

5. min-width (límite mínimo)

width: 20%; min-width: 250px; — mínimo 250px:

mín 250px

6. auto (el navegador decide)

Es el valor por defecto. En un <div>, ocupa todo el ancho:

width: auto (= todo el ancho en bloque)

Detalle: auto se comporta distinto según el tipo de elemento. En bloque ocupa todo; en inline-block se adapta al contenido.

7. fit-content (se adapta al contenido)

La caja ocupa SOLO lo que mide su contenido:

fit-content

Ideal para títulos con fondo, badges o etiquetas que necesitan "abrazar" el texto.

8. min-content (lo más angosto posible)

El ancho mínimo donde el contenido no causa overflow:

min-content estira palabra a palabra

El texto se parte en la palabra más larga. Útil para layouts donde querés ancho mínimo natural.

9. max-content (lo más ancho posible)

El contenido se extiende sin saltos, aunque se salga:

max-content nunca corta el texto en varias líneas

Ojo: puede desbordar el contenedor si el texto es largo.

10. rem (relativo a la tipografía)

width: 20rem; = 20 × 16px = 320px:

20rem

Si el usuario cambia el tamaño de fuente en el navegador, la caja escala con él. Bueno para accesibilidad.

11. calc() (cálculos entre unidades)

width: calc(100% - 80px); — todo menos 80px:

calc(100% - 80px)

Permite mezclar unidades. Se usa mucho cuando tenés márgenes fijos pero el resto tiene que ser flexible.

12. clamp() (responsive moderno)

width: clamp(200px, 50vw, 500px); — entre 200 y 500px, ideal 50vw. Redimensioná la ventana:

clamp responsive

Resumen de todos los valores

Valores absolutos (fijos)

  • 200px — píxeles.
  • 20rem, 10em — relativo a tipografía.

Valores relativos al padre

  • 50% — porcentaje del contenedor.

Valores relativos a la ventana

  • 50vw — % del ancho del viewport.
  • 50vh — % del alto del viewport (para height).

Palabras clave

  • auto — el navegador decide (default).
  • fit-content — se adapta al contenido.
  • min-content — lo mínimo posible.
  • max-content — lo máximo posible.

Límites

  • max-width — límite máximo.
  • min-width — límite mínimo.

Funciones modernas

  • calc(100% - 40px) — cálculos.
  • clamp(min, ideal, max) — responsive con límites.
  • min(100%, 500px) — el menor de los dos.
  • max(50%, 300px) — el mayor de los dos.

Reglas prácticas

  • Para contenido responsive: width: 100%; max-width: 800px; es el patrón más usado.
  • Para cajas que abracen su contenido (como badges): width: fit-content;.
  • Para tipografía responsive sin media queries: clamp().
  • Para layouts con partes fijas y flexibles: calc().
