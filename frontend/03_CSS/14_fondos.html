Propiedades background en CSS

12 pasos progresivos, desde un simple color hasta efectos avanzados combinando múltiples fondos y gradientes.

Las imágenes de ejemplo están incrustadas como SVG inline, así que todo funciona con doble clic, sin archivos externos.
