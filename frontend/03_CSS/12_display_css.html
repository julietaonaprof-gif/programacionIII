Propiedad display en CSS

Define cómo se comporta un elemento: si ocupa toda una línea, si convive con otros en la misma, y si respeta width/height.

1. display: block

Ocupa todo el ancho disponible, salta línea, respeta width y height:

BLOCK 1 BLOCK 2 BLOCK 3

Son <span> (que normalmente son inline), pero les forcé display: block. Cada uno ocupa toda la línea.

2. display: inline

Se quedan en la misma línea. Ignoran width y height:

INLINE 1
INLINE 2
INLINE 3

Son <div> (que normalmente son block), pero les forcé display: inline. Aunque les puse width: 150px; height: 40px, los IGNORA: el tamaño depende solo de su contenido.

3. display: inline-block (lo mejor de los dos)

Se quedan en la misma línea como inline, PERO respetan width/height como block:

INLINE-BLOCK 1
INLINE-BLOCK 2
INLINE-BLOCK 3

Acá sí respeta el width: 150px; height: 40px. Útil para botones, menús, tarjetas pequeñas.

4. display: none (ocultar)

Los elementos con display: none NO se renderizan ni ocupan espacio:

Caja 1 (visible)
Caja 2 (display: none — ¡no aparece!)
Caja 3 (visible, pegada a la 1)

Comparación con visibility: hidden (oculto pero ocupa espacio):

Caja 1 (visible)
Caja 2 (visibility: hidden — hay hueco)
Caja 3 (visible, con hueco antes)

5. display: flex

Los hijos se alinean en una fila (una dimensión):

Elementos HTML por default

Elementos block por default

  • <div>, <p>, <h1> a <h6>
  • <ul>, <ol>, <li>
  • <section>, <article>, <nav>, <header>, <footer>, <main>
  • <form>, <blockquote>

Elementos inline por default

  • <span>, <a>
  • <strong>, <em>, <b>, <i>
  • <img>, <code>, <label>
  • <input>, <button>, <select>

Todos los valores de display

  • block — ocupa toda la línea.
  • inline — convive en la misma línea.
  • inline-block — inline pero respeta width/height.
  • none — oculta el elemento.
  • flex — layout flexible unidimensional.
  • grid — layout bidimensional (filas y columnas).
  • inline-flex, inline-grid — versiones inline de los anteriores.
  • table, table-cell, table-row — comportarse como tabla (raro).
  • contents — el elemento desaparece pero sus hijos quedan (útil con flex/grid).

Cuándo usar cada uno

  • block → contenedores, secciones, layout general.
  • inline → decoración dentro de texto (<span>, <em>).
  • inline-block → botones, menús en línea, tarjetas chicas. (Hoy se usa menos por flexbox.)
  • flex → elementos en una sola línea/columna con alineación flexible.
  • grid → layouts completos con filas y columnas.
  • none → ocultar elementos temporalmente (muy usado con JavaScript para menús, modales, etc.).
