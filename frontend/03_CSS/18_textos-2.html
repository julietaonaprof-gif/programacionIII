Este archivo carga 5 tipografías desde Google Fonts y las aplica para que veas la diferencia en pantalla. Necesitás conexión a internet para que funcione (la primera vez). Después el navegador las cachea.

Paso 3 — Código con JetBrains Mono

JetBrains Mono es una tipografía monoespaciada diseñada específicamente para código fuente. Tiene ligaduras tipográficas (=> se puede ver como una flecha real):

function saludar(nombre) {
  const mensaje = `Hola, ${nombre}!`;
  return mensaje;
}

// Las flechas se ven bonitas: =>

Cómo funcionan las URLs de Google Fonts

La URL que pusimos en el <link> es:

https://fonts.googleapis.com/css2
  ?family=Inter:wght@400;700
  &family=Playfair+Display:ital,wght@0,700;1,400
  &family=JetBrains+Mono:wght@400
  &family=Lobster
  &family=Bebas+Neue
  &display=swap

Desglose parámetro por parámetro

  • family=Inter:wght@400;700 — pide Inter en pesos 400 y 700.
  • family=Playfair+Display:ital,wght@0,700;1,400 — Playfair Display: normal en peso 700 (0,700) e italic en peso 400 (1,400).
  • family=JetBrains+Mono:wght@400 — solo peso 400.
  • family=Lobster — sin especificar peso: trae el único que tiene.
  • family=Bebas+Neue — igual.
  • display=swap — mientras la fuente descarga, mostrar la fallback. Mejor UX.

Los espacios en los nombres se reemplazan por +: "Playfair Display" → "Playfair+Display".

Consejos y buenas prácticas

  • Pedí solo los pesos que vas a usar. Cada peso es un archivo adicional que el usuario descarga. Si vas a usar solo normal y bold, pedí wght@400;700, no wght@100..900.
  • Usá display=swap siempre. Evita el "flash de texto invisible" (FOIT) mientras carga.
  • Siempre poné un fallback genérico al final del font-family: 'Inter', sans-serif. Así, si Google Fonts no responde, el usuario igual ve algo parecido.
  • No uses demasiadas fuentes. Dos o tres máximo es lo profesional: una para títulos, otra para cuerpo, y opcionalmente una monoespaciada para código.
  • Para mejor performance, considerá alojar las fuentes en tu propio servidor (autohospedarlas). Google Fonts es conveniente pero agrega una dependencia externa y una conexión DNS adicional.
  • Considerá las fuentes variables. En Google Fonts aparecen con una etiqueta "Variable". Un solo archivo contiene TODOS los pesos y estilos, así que resulta más liviano que pedir 5 pesos por separado.

Alternativa: @import en CSS

Si no podés modificar el HTML, podés importar las fuentes desde el propio CSS con @import. Debe ir en la primera línea de tu hoja de estilos: 

/* En tu archivo CSS */
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;700&display=swap');

body {
  font-family: 'Inter', sans-serif;
}

El método <link> en el HTML es más performante que @import porque el navegador descubre las fuentes antes y las carga en paralelo. Usá @import solo si no tenés otra opción.
