Paso 18 — @font-face y Google Fonts

Para cargar tipografías personalizadas. El ejemplo va solo en el CSS (comentado), porque requiere archivos de fuente externos. La forma más rápida hoy es usar Google Fonts:

En el HTML:

<link rel="preconnect" href="https://fonts.googleapis.com">
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;700&display=swap" rel="stylesheet">

En el CSS:

body { font-family: 'Inter', sans-serif; }

Con esas tres líneas ya podés usar cualquiera de las ~1500 fuentes de Google Fonts gratis y sin complicarte.
