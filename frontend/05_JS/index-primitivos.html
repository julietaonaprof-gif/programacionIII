Tipos de datos primitivos

Hacé clic en cualquier botón para ver el resultado y el tipo (typeof).

→ El log aparecerá acá

1. number

Todos los números son float de 64 bits (IEEE 754). No existe la distinción entre int y float.

2. string

Texto. Inmutable. Se delimita con ', " o ` (este último permite template literals).

3. boolean

Solo dos valores: true o false. Pero todos los demás valores son "truthy" o "falsy" cuando se convierten.

4. undefined

Una variable declarada sin asignar, una función sin return, una propiedad inexistente.

5. null

Ausencia intencional de valor. Distinto de undefined.

6. symbol (ES6, 2015)

Identificadores únicos. Cada Symbol es distinto, incluso con la misma descripción.

7. bigint (ES2020)

Enteros sin límite de precisión. Se escriben con n al final.
